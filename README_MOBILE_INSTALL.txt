HYBRID ATHLETE COACH v2.1
=========================

WAT DE APP DOET
- 3 krachttrainingen + 2 cardio-/hardloopdagen per week.
- Week 1-12: foundation -> hybrid build -> performance base.
- Week 13-16: kettlebell/functionele kracht.
- Week 17-20: athletic capacity (carries, swings, sled/alternatieven).
- Week 21-24: minder machine-afhankelijk, meer DB/KB/pull-ups.
- Week 25+: automatisch doorlopende 4-weekse hybrid blocks.
- Logt kg, reps en RIR en toont volgende keer je vorige prestaties.
- Geeft eenvoudige progressive-overload suggesties.
- Rusttimer start wanneer je een set afvinkt.
- Readiness check: slaap, energie en spierpijn.
- Logt runs: afstand, duur, hartslag, RPE en notities.
- Progressie: gewicht, pull-ups en 5 km.
- Export/import van je lokale trainingsdata als JSON-back-up.
- Werkt offline nadat de PWA eenmaal is geladen/geinstalleerd.

INSTALLEREN OP ANDROID / SAMSUNG
Deze PWA moet via HTTPS worden geopend om als app te kunnen worden geinstalleerd.

Makkelijkste route:
1. Pak deze ZIP uit.
2. Upload de INHOUD van de map naar een statische HTTPS-host (bijvoorbeeld Netlify Drop,
   GitHub Pages, Cloudflare Pages of Vercel).
3. Open de publieke HTTPS-link in Chrome op je telefoon.
4. Tik op 'Installeren' in de app wanneer die knop verschijnt, of via Chrome-menu > App installeren.
5. Daarna staat 'Hybrid' op je beginscherm en werkt hij als standalone app.

BELANGRIJK
Trainingsdata wordt lokaal op je telefoon/browser opgeslagen. Gebruik onder 'Meer' regelmatig
'Data exporteren' als back-up, zeker voordat je browserdata wist of van telefoon wisselt.
